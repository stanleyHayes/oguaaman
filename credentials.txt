 PRODUCTION — Render (paid) + Vercel + Atlas
------------------------------------------------------------------------------
Database   MongoDB Atlas M0 (free) — cluster0.pioeoms.mongodb.net, db: oguaa
           URI lives in backend/.env (gitignored) and in Render env MONGODB_URI.
           Atlas → Network Access must allow 0.0.0.0/0 (Render has no fixed IPs).
           CORPUS TOP-UP (insert-if-absent, no demo accounts):  cd backend && go run ./cmd/seedlive
           NEVER run cmd/seed here: it drops every collection and refuses
           GO_ENV=production or a database with real members.

API        Render Blueprint (render.yaml at repo root) — Docker, plan 0.5c-512mb (paid),
           region Frankfurt. Service: oguaa-api → https://oguaa-api.onrender.com
           Health check: GET https://oguaa-api.onrender.com/api/health
           Deploy: Render dashboard → New → Blueprint → select this repo;
           Render builds backend/Dockerfile and prompts once for the
           sync:false values (MONGODB_URI, PAYSTACK_SECRET_KEY, ANTHROPIC_API_KEY).

Portal     Vercel (free) — project root directory: frontend/  (frontend/vercel.json
           sets Vite build, SPA rewrites, security headers).
           URL: https://citizen.oguaaman.com  (marketing site: https://oguaaman.com,
                creator studio: https://creator.oguaaman.com)
           Deploy: import repo in Vercel → set Root Directory to "frontend" →
           add the env vars below → deploy. Previews work the same way.

Render env vars (oguaa-api):
  MONGODB_URI            mongodb+srv://… (Atlas — SECRET, prompted by Blueprint)
  MONGODB_DB             oguaa
  JWT_SECRET             auto-generated by Blueprint (generateValue)
  AUTH_REQUIRED          true
  ALLOWED_ORIGIN         https://oguaaman.com,https://www.oguaaman.com,https://citizen.oguaaman.com,https://creator.oguaaman.com,https://admin.oguaaman.com
  PUBLIC_PORTAL_URL      https://citizen.oguaaman.com   (Paystack callback base)
  PUBLIC_API_URL         https://oguaa-api.onrender.com
  UPLOAD_DIR             /app/uploads
  PLATFORM_FEE_PERCENT   5
  PAYSTACK_SECRET_KEY    sk_live_… — set in the Render dashboard only, never in git
                         (blank in production = paid flows answer 503; never simulated)
  ANTHROPIC_API_KEY      (blank in production = the AI assistant answers 503 ai_unavailable)
  CLOUDINARY_CLOUD_NAME / CLOUDINARY_API_KEY / CLOUDINARY_API_SECRET
                         signed image uploads (blank = clients fall back to the API's /uploads)

Vercel env vars (frontend):
  VITE_API_URL                  https://oguaa-api.onrender.com
  (No Cloudinary or Paystack variables on Vercel: the API signs image uploads,
   and Paystack checkouts need no public key.)

Hosting caveats:
  • The Render instance is paid (0.5c-512mb), so it doesn't sleep.
  • Render disk is EPHEMERAL: /uploads files vanish on redeploy/restart.
    Durable member images must go through Cloudinary (set the CLOUDINARY_* keys).
  • Only $PORT is exposed publicly — the gRPC server (50051) is NOT reachable
    from the internet on Render; clients use REST only (GraphQL is off in
    production unless GRAPHQL_ENABLED=true).
  • Vercel preview URLs are NOT in ALLOWED_ORIGIN — add them (or a custom
    domain) to ALLOWED_ORIGIN on Render if you need previews to call the API.
  • If the Vercel project name differs, update ALLOWED_ORIGIN / PUBLIC_PORTAL_URL
    on Render AND the canonical/OG/sitemap URLs in frontend/ (index.html,
    public/robots.txt, public/sitemap.xml) — now say citizen.oguaaman.com;
    the marketing site generates its own at build (plugins/seo-prerender.ts).
